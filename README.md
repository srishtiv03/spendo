# Spendo 💸  

[Live Demo](https://spendo-beta.vercel.app/)

Spendo is an **AI-powered finance platform** that helps users track, analyze, and optimize their spending.  
Built with modern web technologies, it combines intelligent insights, beautiful UI, and secure authentication to deliver a smooth finance management experience.  

---

## ✨ Features
- 🔐 Secure authentication with **Clerk** and **Arcjet**
- 🤖 AI finance assistant powered by **Google Generative AI**
- 📊 Interactive financial charts with **Recharts**
- ⚡ Real-time workflows with **Inngest**
- 🎨 Clean, responsive design using **Tailwind CSS** + **Radix UI**
- 📧 Transactional emails via **Resend**
- 🛡️ Data validation with **Zod**
- 🔔 Smooth notifications with **Sonner**

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15, React 19  
- **Database & ORM**: Prisma 6  
- **Authentication & Security**: Clerk 6, Arcjet  
- **UI/Styling**: Tailwind CSS 4, Radix UI, Sonner  
- **Charts**: Recharts  
- **Validation**: Zod  
- **Emails**: Resend  
- **AI**: Google Generative AI  
- **Workflows**: Inngest 3
